# Career-lead roadmap

## Destination

Find and agree the path to a completed first team position-focus cycle by the end of January 2027. The exact deadline and definition of completion remain to be confirmed.

## Notes

- [Starting PRD](../../docs/PRD.md)
- [Accepted starting milestones](../../docs/ROADMAP.md)
- [Local tracker conventions](../../docs/agents/issue-tracker.md)
- Milestone classification is explicit: milestone.md plus Kind: milestone. Each milestone folder also has its own planning map.
- Detailed implementation breakdowns follow planning and user review.

## Decisions so far

- Record the five accepted starting outcomes as milestones, keeping their readiness at needs-info while details are planned.
- Use local Markdown under .scratch for milestones, maps, specifications and tickets; these files are eligible for Git tracking.
- Keep the five default triage roles and use Kind independently for milestone classification.
- Use feature groups and a detail sheet with separate metadata on the live TypeScript ticket board.

## Not yet specified

- Confirm the January date and whether completion means submission, reviewed agreement or formal approval.
- Plan each milestone through its own map before specifying and ticketing implementation.
- Authentication options, visibility rules, hosting, database recovery and available development capacity.

## Out of scope

- Automated messaging, transcription, AI analysis and broad HR functionality for the first January cycle.

## Ticket board

Open http://127.0.0.1:4393 after starting npm run tickets. The board reads recorded milestones and individual issues live. It currently contains five milestones and no implementation tickets.
