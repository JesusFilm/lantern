# Base 3 — Document grid

The base repeats section headings inside separate cards and gives destructive actions almost the same visual weight as edits. The varying goal lengths also make the right edge feel irregular. A page of four objectives reads as multiple panels rather than one position-focus document.

This alternative presents one continuous document grid with shared Objective and SMART goals headings. Each concern gets an aligned row; an unobtrusive number and concern label distinguish objectives without changing the optional-focus structure. Stable, right-aligned goal action rails separate reading from editing. Pale objective cells help users follow a row across to its goals. Compact secondary edit buttons have clear hit areas, while remove actions are smaller and muted.

Typography stays at a readable 15–16px with generous line height; spacing is concentrated between ideas rather than repeated card frames. Long content remains visible. On narrow screens rows stack, and a SMART goals label returns for clarity. The existing spacious field dialogs and all in-memory interactions remain intact.

Tradeoff: the shared grid is more structured and denser than a document-page layout. The long leadership goal still sets its row height; this is intentional to preserve the full overview rather than truncate or collapse content.
