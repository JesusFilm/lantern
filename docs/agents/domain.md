# Domain guidance

Before documenting or changing domain behavior, read the [business rules](../rules/README.md), the root `GLOSSARY.md` if present and relevant records in `docs/adrs/`. Use established domain terms in requirements and code. Follow `docs/adrs/AGENTS.md` when a change requires an architectural decision.

Agents may draft and maintain rule entries; only the owner approves their meaning. Record conflicting sources and open decisions rather than silently choosing.
